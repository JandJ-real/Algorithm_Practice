## 二、算法专题归纳

### 2.1 图论 —— Dijkstra

**文件：01.cpp**

标准 Dijkstra 的三处扩展：
1. **最短路计数** `cnt[v] += cnt[u]`（非 `++`，是累加）
2. **多权值最优**：同等最短路下比较救援队数量
3. **前驱记录**：反向追踪路径后 `reverse` 输出

```
关键易错点：
- 过期节点判断：curdist > dist[u] 时跳过（优先队列懒删除）
- push 时机：只在找到更短路时 push，等长时仅更新值不重入队
```

### 2.2 数据结构 —— 并查集

**文件：07.cpp（家庭房产）、10.cpp（朋友/敌人）、13.cpp（红色警报）、24（部落）**

**通用模板：**
```cpp
int fa[N];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
void merge(int x, int y) { fa[find(x)] = find(y); }
```

**07.cpp 要点（聚合型并查集）：**
- `fa[0] = -1` 防止全局数组默认值 0 引发根节点误判（真实 bug 记录）
- 合并时选**编号更小的**作为根节点
- 先存所有关系，**最后统一合并**，避免因输入顺序导致的提前合并错误
- 合并同步维护：`housenum`、`area`、`peoplenum`

**10.cpp 要点（朋友+敌人双关系）：**
- 并查集管理"朋友"集合，`enemy[a][b]` 矩阵管理"直接敌对"
- 四种情况：No problem / OK / OK but... / No way

**13.cpp 要点（关键点删除）：**
- 统计删点前的连通分量数 `cnt_before`
- 删点后重建并查集，统计 `cnt_after`
- 若 `cnt_after > cnt_before + 1`，则该点是关键点（红色警报）
- `for(auto& x : arr)` ← **必须加引用，否则是副本！**

### 2.4 BST 验证

**文件：04.cpp**

给定后序序列，判断是否为合法 BST 或镜像 BST：
- 先扫一遍确定是否需要镜像标志 `ismirror`
- `check(root, l, r)`：递归划分左右子树，验证每段能被完全覆盖
- 顺便重建后序数组（`hou[]`）用于输出

```
核心边界条件：
- root > r 时直接 return（节点不存在）
- l2 - l1 + r2 - r1 != r - l + 1 → 非法结构，flag=0
```

### 2.8 LIS —— 最长上升子序列

**文件：14.cpp**

```cpp
vector<int> dp;
for (int x : arr) {
    auto it = lower_bound(dp.begin(), dp.end(), x);
    if (it == dp.end()) dp.push_back(x);
    else *it = x;
}
// dp.size() 即 LIS 长度
```

**Dilworth 定理变体（题14的精髓）：**
- "最少下降子序列划分数" = "最长上升子序列长度"
- 即：`upper_bound` 替换（非严格递增时用 `upper_bound`）

void dfs(int cur, double v) {
    if (isLeaf[cur]) { ans += v * skill[cur]; return; }

### 2.14 快乐数 & 质数筛

**文件：029（特立独行的幸福）**

**快乐数判定：**
```cpp
// 数字各位平方和循环，用 set 检测是否进入循环
set<int> seen;
while (n != 1 && !seen.count(n)) {
    seen.insert(n);
    int next = 0;
    while (n) { next += (n%10)*(n%10); n /= 10; }
    n = next;
}
// n==1 → 快乐数
```

**"特立独行"额外条件：** 快乐数 + 其本身不在其他数的快乐数路径上（即独立存在）

## 三、常用技巧 & 易错点汇总

### 技巧

| 技巧 | 说明 | 相关题目 |
|------|------|---------|
| `#define int long long` | 防止溢出，全局替换（用 `signed main()`）| 全部 |
| 交叉乘法比较分数 | `a*d > b*c` 替代 `a/b > c/d` | 03, 19 |
| 并查集合并时维护聚合数据 | merge 内同步累加 | 07 |
| 优先队列懒删除 | `if (curdist > dist[u]) continue` | 01 |
| `map` 键用 `int` 比 `string` 快 | 地址类题目尤为重要 | 02 |

| `vector` 作 `map` 键 | `map<vector<int>, int>` 完全合法 | 039 |
| `(int)ans` 截断浮点 | 浮点累加结果强制转 int 输出 | 20 |

### 易错点

| 错误类型 | 具体案例 | 文件 |

| 删点后并查集未重新初始化 | 每次查询前需 `init()` | 13 |

## 六、赛场策略

1. **开局**：先快速扫描所有题，按难度归类，优先做 ① 类保分。
2. **二叉树题**：认准"后序/前序 + 中序 → 重建 → BFS层序"框架，10分钟内可出。
3. **并查集题**：初始化 `fa[0]=-1`，输入全部读完再统一合并。
4. **回文串**：n < 1000 直接暴力 O(n²)，不冒险写 Manacher。
5. **LIS 类**：认出 Dilworth 定理变体——"最少下降子序列数 = LIS 长度"。
6. **排序题**：多关键字比较器 `lambda` 写法更安全，避免运算符重载的隐患。
7. **时间分配**：1道30分题卡死超过30分钟时，果断跳题。
8. **输出格式**：最后一行不换行，固定宽度用 `printf`，浮点保留位数用 `fixed << setprecision`。
