一、重链剖分

  定义

  对树上每个节点，定义重儿子为子树最大的儿子，其余为轻儿子：

  重边：节点 → 重儿子
  轻边：节点 → 轻儿子
  重链：极大的连续重边路径

          1(sz=7)
         / \
        2   3(sz=1) ← 轻儿子
     (sz=5)
      /  \
     4    5(sz=1) ← 轻儿子
  (sz=3)
    / \
   6   7
  (1) (1)
  重链：1→2→4，3独立，5独立，6独立，7独立

  核心性质

  ▎ 从根到任意叶节点，路径上轻边数量 ≤ log n

  证明： 每经过一条轻边 u→v，意味着 v 是轻儿子：
  sz[v] < sz[u] / 2   （否则 v 就是重儿子了）
  子树大小每过一条轻边至少减半，最多减半 log n 次，所以轻边 ≤ log n。

  二、DSU on Tree（树上启发式合并）

  解决的问题

  ▎ 对每个节点 u，计算其整棵子树的某个统计量
  ▎ 朴素做法：每个节点单独 DFS → O(n²)
  ▎ DSU on Tree：O(n log n)

  核心思想

  重儿子的数据 → 直接继承，不重算
  轻儿子的数据 → 处理完就丢，到父亲时重新插入

  为什么只丢轻儿子的数据？

  因为重儿子的子树 ≥ 整棵子树的一半，丢掉重算代价太大。轻儿子的子树 < 一半，重算相对便宜。

  算法步骤（配合DFS序）

  dfs(u, keep):
      ① 对所有轻儿子 v：dfs(v, keep=false)   // 算完就清空
      ② 对重儿子 h：  dfs(h, keep=true)      // 保留数据
      ③ 把所有轻儿子子树的节点逐个 add 进全局桶
      ④ add(u) 自身
      ⑤ 记录 ans[u]
      ⑥ 若 keep=false：把整棵子树全部 del 掉

  执行过程示意（以上图为例）：

  dfs(1, false):
    ① 轻儿子3: dfs(3,false) → add(3),记录ans[3],del(3)  桶:{}
    ② 重儿子2: dfs(2, true)
        ① 轻儿子5: dfs(5,false) → add(5),ans[5],del(5)   桶:{}
        ② 重儿子4: dfs(4, true)
            ① 无轻儿子
            ② 无重儿子(叶)... 实际4有子6,7，6或7是重儿子
            ... 最终桶:{4,6,7}，ans[4]记录，keep=true不清
        ③ 无需插入(4无轻儿子子树)
        ④ add(2) → 桶:{2,4,6,7}
        ⑤ 记录 ans[2]
        ⑥ keep=true，不清空
    回到dfs(1):桶已有{2,4,6,7}
    ③ 插入轻儿子3的子树: add(3)  → 桶:{2,3,4,6,7}
       插入轻儿子5的子树: add(5)  → 桶:{2,3,4,5,6,7}
    ④ add(1) → 桶:{1,2,3,4,5,6,7}
    ⑤ 记录 ans[1]
    ⑥ keep=false，全部 del

  为什么是 O(n log n)

  每个节点被 add 的次数 = 它到根路径上轻边的数量 + 1

  节点 3：路径 3→1，经过1条轻边 → add 2次
  节点 5：路径 5→2→1，经过1条轻边(5→2) → add 2次
  节点 6：路径 6→4→2→1，经过0条轻边(全是重边) → add 1次

  由重链剖分性质，轻边数 ≤ log n，所以每个节点最多 add O(log n) 次，总计 O(n log n)。

  三、应用到颜色平衡树

  全局维护三个结构，用 O(n) 空间代替 O(n×C)：

  cnt[c]   = 当前桶中颜色c的频次
  fcnt[f]  = 当前桶中频次为f的颜色数量
  distinct = fcnt中非零项的数量（有多少种不同频次）

  平衡条件：distinct == 1

  add/del 操作 O(1) 维护三者一致：

  add(颜色c):
    旧频次 cnt[c] → 从 fcnt 中减1，若变0则 distinct--
    cnt[c]++
    新频次 cnt[c] → 加入 fcnt，若从0变1则 distinct++

  del(颜色c):
    对称操作

  整体流程：

          ┌─────────────────────────────┐
          │  DFS序预处理（tin/tout）      │  O(n)
          │  重儿子预处理                 │  O(n)
          └─────────────────────────────┘
                         ↓
          ┌─────────────────────────────┐
          │  dfs2：                      │
          │  轻儿子 → 处理后清空           │  每个节点 O(log n) 次
          │  重儿子 → 保留                │
          │  add 轻子树 + 自身            │
          │  distinct==1 ? ans++         │  O(1) 查询
          └─────────────────────────────┘

  这样空间从 O(n²) 降到 O(n)，时间从 O(n²) 降到 O(n log n)。
