> 整理自 2021–2024 年刷题记录，共 23 道题。

## 一、算法知识点速查

### 1. 最短路 / 图论

#### Dijkstra（P8740）
- 边权为 LCM(u, v)，需用 `__int64` 或 `long long`
- 朴素版 O(n²)，优先队列版 O((V+E) log V)
- **关键公式**：`lcm(a, b) = a / gcd(a, b) * b`（先除后乘，防溢出）
- 注意：LCM 可能非常大，边权爆 `int` 要用 `long long`

#### Floyd-Warshall 变体（P9236，最大瓶颈路）
```cpp
// 最大瓶颈路（最大化路径最小边权）
dp[i][j] = max(dp[i][j], min(dp[i][k], dp[k][j]));
```
- 多条边取最大权（初始化时取 max）
- 适用于小图（n ≤ 300）

#### 二叉提升 / LCA（P10391）
- `parent[i][j]` = 节点 i 的 2^j 祖先
- `tohere[i][j]` = 根到 i 的路径上第 j 种零食数量
- 路径查询用容斥：`ans = to[u] + to[v] - to[lca] - to[parent[lca]]`

---

### 2. 动态规划

#### 最长非递减子序列变体（P8776）
- `f[i]` = 以 i **开头**的最长非递减子序列长度
- `g[i]` = 以 i **结尾**的最长非递减子序列长度
- 枚举连接点：`ans = max(g[l] + f[r] + k)`，其中中间 k 个元素连续

#### 搜索 + 剪枝（P9234，篮球得分）
- 上界剪枝：当前和 > m，直接返回
- 下界剪枝：当前和 + 剩余所有元素 < m，直接返回
- 折半搜索（meet-in-the-middle）：n 较大时将问题拆为两半

---

### 3. 二分搜索

#### 二分答案模板
```cpp
int lo = 1, hi = n;
while (lo < hi) {
    int mid = (lo + hi) / 2;
    if (check(mid)) hi = mid;
    else lo = mid + 1;
}
```

#### P8775（石块权重）
- 二分窗口长度，前缀和检验任意连续区间和 ≥ 2x

#### P10389（方差分组）
- 二分组大小，排序后滑动窗口计算方差
- **方差公式**：`Var = E[x²] - (E[x])²`
- 用两个前缀和数组：`sum_x[]`、`sum_x2[]`，避免浮点误差用整数比较

---

### 4. 前缀和 / 差分

#### 一维前缀和（P8772，P8775，P10389）
```cpp
pre[0] = 0;
for (int i = 1; i <= n; i++) pre[i] = pre[i-1] + a[i];
// 区间 [l, r] 的和 = pre[r] - pre[l-1]
```

#### 贡献法（P8772）
- 每个元素对后续所有位置的贡献 = `a[i] * (total_sum - pre[i])`
- 避免 O(n²) 暴力枚举

---

### 5. 数学 / 数论

#### 差平方数（P9231）
- `a² - b² = (a-b)(a+b)`，可表示为差平方的数：
  - 奇数（令 a-b=1，a+b=n）
  - 4 的倍数（令 a-b=2，a+b=n/2）
  - **不能表示的**：n=1、n=2、4k+2 形式的数
- 1 到 n 中可表示数的个数 ≈ `ceil(n/2)`

#### XOR 性质（P8773）
- 前缀 XOR：`xor[i] = a[1] XOR ... XOR a[i]`
- 区间 XOR：`a[l..r] = xor[r] XOR xor[l-1]`
- 利用 HashMap 预处理最小下标

#### 大数（P10390）
- 用 `__int128` 处理超大中间结果
- 输出 `__int128` 需自己写打印函数

---

### 6. 贪心

#### 训练场次调度（P10387）
- 按最大可参加场次升序排列
- 枚举"实际场次"k，计算费用 = `s*k + Σ(count * max_sessions - count * k)`
- 维护前缀累计 count，一次遍历搞定

---

### 7. 回溯 / DFS

#### 拉丁方 / 数独类（P10386）
- 5×5 网格，约束：每行、每列、对角线和都被 5 整除
- DFS 按格子顺序填，每次填完即时验证行/列约束
- 剪枝：填完一行后验证行约束，填完一列后验证列约束

#### 8 方向 DFS 框架（P9237骨架）
```cpp
int dx[] = {0,0,1,-1,1,1,-1,-1};
int dy[] = {1,-1,0,0,1,-1,1,-1};
```

---

### 8. 字符串

#### 类回文计数（P9232）
- 从两端向中间双指针扫描
- `s[l] > s[r]` → 字典序大于其反转，计入答案

## 二、常用代码模板

### GCD / LCM
```cpp
long long gcd(long long a, long long b) { return b ? gcd(b, a%b) : a; }
long long lcm(long long a, long long b) { return a / gcd(a,b) * b; }
```

### 快速幂
```cpp
long long qpow(long long base, long long exp, long long mod) {
    long long res = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1) res = res * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return res;
}
```

### 并查集
```cpp
int fa[MAXN];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
void unite(int x, int y) { fa[find(x)] = find(y); }
```

### 拓扑排序（BFS）
```cpp
queue<int> q;
for (int i = 1; i <= n; i++) if (indeg[i] == 0) q.push(i);
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
        if (--indeg[v] == 0) q.push(v);
    }
}
```

## 三、容易踩的坑

| 坑点 | 说明 |
|------|------|
| **整数溢出** | LCM、大数相乘先用 `long long`，必要时 `__int128` |
| **先除后乘** | `a / gcd(a,b) * b` 而非 `a * b / gcd(a,b)` |
| **前缀和下标** | `pre[0]=0`，区间 [l,r] = `pre[r]-pre[l-1]`，注意 1-indexed |
| **二分边界** | `lo < hi` 还是 `lo <= hi`，`hi = mid` 还是 `hi = mid-1` 要想清楚 |
| **浮点方差** | 用整数公式 `n*Σx² - (Σx)²` 比较，避免精度问题 |
| **图的多重边** | Floyd 初始化时同一对节点取最大权 |
| **填空题答案** | 有些题暴力预计算后直接硬编码答案，注意检查输入格式 |
| **DFS 访问标记** | 回溯时记得恢复 `vis[x] = false` |
| **读入速度** | 数据量大时加 `ios::sync_with_stdio(false); cin.tie(0);` |

## 五、比赛策略提醒

1. **填空题先做**：有固定答案，暴力打表即可，不要卡太久
2. **编程题从简单开始**：能拿部分分也要写，写上暴力骗分
3. **溢出检查**：涉及乘法、LCM、阶乘的题，第一反应用 `long long`
4. **图论题**：先确认是有向/无向、有无负边权，再选算法
5. **DP 题**：先想状态定义，再想转移，最后想初始化和边界
6. **时间复杂度估算**：n ≤ 10⁶ 用 O(n log n)，n ≤ 10³ 可以 O(n²)，n ≤ 20 可以爆搜
